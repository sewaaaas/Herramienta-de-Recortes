# ShotFlow

ShotFlow es una herramienta de capturas de pantalla para Windows, hecha con Python y PyQt6.

## ¿Por qué la creé?

ShotFlow nació al observar que algunos usuarios tenían dificultades para hacer capturas de pantalla y añadir anotaciones, por lo que recurrían a Paint. Además, las restricciones de seguridad del entorno corporativo limitaban el uso de herramientas externas. Por eso decidí crear una alternativa sencilla para capturar, señalar y compartir imágenes de forma más práctica.

## Qué permite hacer

- Seleccionar una zona de la pantalla y ajustar el recorte.
- Añadir anotaciones antes de copiar o guardar la captura.
- Usar atajos como `Impr Pant` y `Ctrl + Shift + S`.
- Acceder a las opciones desde la bandeja del sistema.
- Configurar el inicio con Windows.

## Cómo ejecutarla

Necesitas Windows y Python con las dependencias instaladas.

```powershell
pip install -r requirements.txt
python ShotFlowV1.py
```

## Estado del proyecto

La aplicación funciona desde el código fuente y sigue recibiendo mejoras. Por ahora no tiene instalador.
